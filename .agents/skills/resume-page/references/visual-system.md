# JD Collector 简历视觉与打印规范

## 来源与取舍

基线来自 `早期独立简历页面`：白色 A4 纸张、深蓝主色、姓名/岗位/联系方式首屏、浅蓝公司条、紧凑项目列表和打印 CSS。旧版长容器分页保护曾导致第二页大面积空白；新模板只保护短标题组，长经历允许自然跨页。

## 视觉令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| ink | `#172033` | 正文 |
| muted | `#536174` | 次要信息 |
| primary | `#174a7c` | 姓名、标题 |
| accent | `#1f6fb2` | 标记、边线 |
| line | `#d8e2ee` | 分隔线 |
| soft | `#edf5fc` | 公司条背景 |

字体优先 `Microsoft YaHei`, `PingFang SC`, `Noto Sans CJK SC`, Arial, sans-serif。屏幕正文约 14px；打印正文 9.5–10.5pt、行高 1.42–1.52。

## A4 结构

- 纸张宽 `210mm`、最小高 `297mm`；打印页边距由组件内边距控制。
- 屏幕居中并显示轻阴影；窄屏移除阴影并缩小照片。
- 页眉以姓名/目标岗位为主，联系方式和照片为辅。
- 联系方式区最小高度为 `15.5mm`，给照片保留空间，同时减少个人概述前的留白。
- H2 建立一级区块；H3 表示公司/经历组；H4 表示项目和角色。
- 技术能力宽屏/打印可用两列，窄屏改为一列。

## 分页规则

```css
@page { size: A4; margin: 0; }
* { print-color-adjust: exact; -webkit-print-color-adjust: exact; }
h2, h3, h4 { break-after: avoid; }
h2 + *, h3 + *, h4 + * { break-before: avoid; }
li, p { orphans: 2; widows: 2; }
```

不要对整个项目、公司或 section 设置无条件 `break-inside: avoid`。若内容超过一页，浏览器会将整个容器推到下一页并制造空白。必须实际检查打印结果。

## 内容密度

- 经历使用“动作 + 技术/难点 + 可验证结果”。
- 同一项目保留 3–6 个高信息量 bullet。
- 不为压成一页而使用难读字号；完整版允许两页，但不接受几乎空白的尾页。
- 定向版调整顺序、删减低相关项、强化匹配证据，不改变事实。
