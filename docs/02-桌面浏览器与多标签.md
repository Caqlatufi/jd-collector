# 桌面浏览器与多标签

负责单窗口、多标签、网页导航、窗口生命周期和通用桌面桥接。平台账号身份及登录态由[账号功能](03-招聘平台账号与登录态.md)定义；Agent截图和受限页面动作是[采集识别功能](04-JD采集与截图识别.md)的一部分，不归本功能维护。

## 1. 需求分析

### 桌面入口增量范围

桌面顶部仅保留标签栏和地址栏，取消固定标签说明与状态说明的独立占位行。正常状态不显示提示图标；异常或空白页在地址栏旁显示小图标，完整消息通过悬停提示查看。

Electron 从 `frontend/src/app` 接入，复用现有 Vue 页面和本地后端。`src/common/desktop` 提供类型化请求、事件订阅和浏览器模式降级；业务模块通过公共能力发起请求、订阅结果，不直接依赖 Electron。

提供单窗口桌面工作台、常驻多标签、网页状态和开发启动命令。顶部第一项固定为不可关闭的 JD Collector 标签；BOSS 网页在同一窗口的其他可关闭标签中展示，不再单独弹出招聘浏览器。同网站可打开多个职位，切换保留未提交输入与滚动状态。具备新标签、地址输入、前进、后退、刷新、关闭单页和返回固定工作台操作；外站新窗口链接挂入新标签。网页操作统一放在顶部标签栏和地址栏，窗口操作使用系统标题栏；移除 Vue 工作台的“桌面工具”按钮与抽屉。

固定工作台无关闭按钮，主进程同时拒绝关闭或替换请求；关闭最后一个外站标签回到工作台。关闭整个客户端窗口才退出，退出后会话持久化，未保存页面状态不跨退出恢复。正常交付保持运行，隔离测试单独清理。平台登录和读取统一使用 Electron 内置标签；account 定义平台规则，Agent workflow 执行岗位读取，用户只操作网站登录，历史 Java 会话快照仅作只读兼容。

完成标准：真实 Electron 启动现有工作台，公共请求与推送事件生效，网页窗口持久化状态可在重启后读取，网页模式保持可用；基础规范中明确进程边界和业务模块接入方式。





不建设工作台自身登录鉴权；不在业务模块直接导入Electron。

## 2. 架构设计

### 桌面层目录与通信

```text
frontend/src
├─ app
│  ├─ electron/[+] main.ts, preload.ts, offline.html, browser.html, browser.ts, build.mjs, launch.mjs
│  ├─ components/[-] DesktopTools.vue
│  └─ [~] App.vue
└─ common/desktop
   ├─ [+] contract.ts        命令/结果/事件契约，纯 TypeScript
   ├─ [+] client.ts          request + on，网页模式返回明确不可用
   └─ main/[+] register.ts, browserWindows.ts  主进程能力实现

业务模块 / app 壳
  -> common/desktop/client.request(command, payload)
  -> app preload（固定通道、参数和事件包装）
  -> common/desktop/main（校验调用方，执行原生能力）
  -> result / desktop event
  -> client.on(event, callback)，卸载时取消订阅
```

工作台 preload 只暴露受限桥接对象。外部网页窗口保持 sandbox/contextIsolation，关闭 nodeIntegration，无工作台 preload；不能调用本机 IPC。请求使用 Promise 返回结果，状态变化使用独立事件，不靠无返回值事件模拟可失败的业务动作。

```text
单一 BrowserWindow（本地工具栏，98px；标签栏 + 地址栏）
  ├─ WebContentsView：固定 JD Collector / 原有 Vue，不可关闭
  ├─ WebContentsView：外站标签 A
  ├─ WebContentsView：外站标签 B，隐藏但保持运行
  └─ WebContentsView：外站新窗口链接，继承来源 session
切换 -> 变更 activeKey / 可见性 -> 原文档继续使用
关闭单页 -> 移除该 view 并释放 webContents
关闭最后一个外站 -> 回到固定 JD 标签
关闭客户端窗口 -> 显式释放所有 webContents 并退出
```

主进程只接受工作台 view 主 frame 或固定本地 browser.html 工具栏主 frame 的命令；工具栏限浏览器命令与返回工作台。jd-workbench 为保留 key，固定项在主进程拒绝关闭、替换和外站导航。外站标题用文本渲染，地址状态去除查询串与片段，不传递会话原文。

### 会话容器边界

每个项目使用自己的桌面快捷方式名和窗口标题，避免同名快捷方式覆盖与窗口误认。`JD_DESKTOP_BACKGROUND_WORKFLOW=true` 时选中标签可接受绑定截图的后台原生输入，切换标签仅改变本窗口view，不激活主窗口；宿主仍须可见且未最小化，目标、代次、几何、时效与像素校验不变。系统窗口位置、尺寸和最大化状态存入该userData的`window-placement.json`，重启只恢复仍与现有显示器相交的位置。

### 页内缩放

工具栏提供“− / 当前百分比 / ＋”，百分比按钮恢复100%；Ctrl + 加号/减号调整当前页，Ctrl + 0恢复。工作台及外站使用`setZoomMode('isolated')`，范围50%–300%，切换/导航时按各WebContents独立保留，关闭标签后不承诺缩放跨重启保留。缩放不修改系统窗口位置或尺寸，不传播到同站点其他标签或其他客户端。缩放增加视觉代次，旧截图不能继续发送输入，必须重新capture并校准坐标。

Agent可在已有图像证据下用受限`key --key-code ZoomIn|ZoomOut|ZoomReset`，仍执行原生截图、像素和几何校验；此类缩放按键不授予搜索文字输入权限，不暴露任意快捷键或页面脚本。[Electron缩放接口](https://www.electronjs.org/docs/latest/api/web-contents#contentssetzoommodemode)定义同源共享与隔离模式。

同一电脑的两个独立项目需分别固定后端端口、数据库、criteria路径、识别目录、查重接口及Electron userData。`local/env.json` 设置 `JD_COLLECTOR_ISOLATED=true` 后，PowerShell启动、Node桌面启动及workflow/筛选连接优先采用该项目本地配置，避免继承另一项目的连接设置。保留原客户端既有userData，无须复制或清除登录会话。单实例锁和workflow管道按userData隔离，启动器互斥锁按项目路径隔离；停止脚本只接受本项目JAR的Java进程。两个项目的端口、userData不能相同。

Electron 标签以 key 标识页面，以 sessionKey 标识 `persist:` session（未指定时回退为 key）。普通站点由 UI 提供 sessionKey；已注册招聘平台由主进程按域固定分区，子域和弹出标签复用所属平台会话，其余弹出页继承来源分区。数据保存在本机 userData，不进入 Git；测试显式使用临时 userData。该浏览器状态不导入 Java 账号表；平台登录态语义见[账号功能](03-招聘平台账号与登录态.md)，采集契约见[采集识别](04-JD采集与截图识别.md)。

## 3. 开发方案

### Electron 入口与公共工具

安装 Electron 与 esbuild 为前端开发依赖；主进程、preload 和工具栏由 `src/app/electron/build.mjs` 独立打包至 `dist-electron`。唯一主窗口加载 browser.html 工具栏，固定工作台 WebContentsView 加载本地 `/jd-collector/`（生产7890、开发3002）；外站 view 与其并列挂载。后端沿用现有 ops，Electron 不重复启动或结束 Java。

`desktop:build` 构建主进程/preload；`desktop:start` 构建后启动本地后端页面；`desktop:dev` 启动独占3002的 Vite 并打开桌面开发窗口；`desktop:check` 执行专用 tsc --noEmit 与模块边界检查；`test:desktop` 执行真实 Electron 测试。桌面依赖安装需要 Node22.12+，不得偷偷修改系统默认 Node。

安装依赖后在Node22.12+下执行 `desktop:install` 下载并校验Electron二进制。Vite代理明确指向127.0.0.1，匹配后端回环监听地址。二进制就绪后本机原有Node18可执行构建/启动脚本。



### 请求与事件契约

公共接口 `desktop.request(command, payload)` 返回 Promise；`desktop.on(event, callback)` 返回取消订阅函数。契约集中于 `common/desktop/contract.ts`。

| 命令 | 输入 | 返回 |
| --- | --- | --- |
| runtime.info | 空对象 | 客户端版本、平台 |
| app.retry | 空对象 | 是否已发起重新加载 |
| window.minimize / window.toggleMaximize | 空对象 | 窗口状态 |
| browser.open | key、url、title?、sessionKey? | 新建或复用标签并聚焦；默认分区兼容旧 key |
| browser.show | 空对象 | 聚焦当前主窗口，返回固定项及存活外站标签数组 |
| browser.focus | key | 激活既有标签，不触发导航 |
| browser.navigate | key、url | 当前标签访问新地址 |
| browser.back / browser.forward / browser.reload | key | 当前标签前进、后退、刷新结果 |
| window.focus | 空对象 | 激活固定工作台标签 |
| browser.close | key | 仅该标签的 closed 状态 |
| browser.list | 空对象 | 固定 JD Collector 在第一项，随后为外站标签 |
| browser.session | key | Cookie 数量、持久化标记；不返回 Cookie/Token 原文 |

事件 `window.changed` 传递窗口状态，`browser.changed` 传递 key、title、脱敏 URL、loading/ready/blank/failed/closed、active、canGoBack、canGoForward 和提示。主进程注册固定处理器，校验来源为工作台或本地工具栏主 frame，并校验 payload；preload 不暴露 ipcRenderer、任意通道、文件或脚本执行。

BrowserWindows 接收 app 创建的唯一主窗口和固定工作台 view，用 Map 管理至多30个外站 view。固定项 key=jd-workbench、pinned=true，不能 close/open/navigate 替换；切换不重建 DOM，最后一个外站关闭后激活工作台。工具栏 browser.ts 经 esbuild 打包，browser.html 复制至 dist-electron。网页 URL 默认HTTPS，key/sessionKey 限100个字母、数字、冒号、下划线或短横线；新窗口链接使用 createWindow 返回同分区的新 view。关闭单页显式关闭 webContents，退出释放全部 view。同站点 sessionKey 按 hostname 派生，兼容既有 www_zhipin_com 等分区。

网页模式调用公共桌面命令得到 `DESKTOP_UNAVAILABLE`，订阅返回可调用的空清理函数。App.vue 不再导入或挂载 DesktopTools，也不为该入口保留 desktopMode 判断；移除对应抽屉组件。顶部 browser.* 承担网页操作，系统标题栏承担窗口操作；公共窗口和会话摘要命令继续保留，供桥接调用及测试使用。外部网页只允许 http(s)，生产只允许 https，窗口数据独立。捕获实际导航和延迟空白事件；打开请求的成功只表示窗口建立，不表示外站已登录。



### 异常与维护

browser.html 移除独立状态行与固定提示文本，header 高度与 BrowserWindows 的 TOOLBAR_HEIGHT 同步为98px；所有工作台及外站 view 从 y=98 开始，收回34px。普通网页状态置于地址栏 title；失败、空白或输入错误用同一地址行的警告图标及 title/aria-label 表达，正常时 hidden，不另占一行。

IPC 错误返回明确 code/message 并由公共客户端转换为 Error；缺失后端时工作台显示离线页及重试入口。事件通知不能带底层 Electron 对象或秘密。公共能力需扩展时依次更新契约、preload 白名单、主进程校验、测试与文档，业务模块不增加环境判断分支。

实现参考 [Electron IPC](https://www.electronjs.org/docs/latest/tutorial/ipc)、[Session](https://www.electronjs.org/docs/latest/api/session) 和 [进程隔离约定](https://www.electronjs.org/docs/latest/tutorial/security)。

多标签承载参考 [WebContentsView](https://www.electronjs.org/docs/latest/api/web-contents-view)，原生标签不进入业务模块或 Vue 页面 DOM。

### 验证说明

双客户端隔离夹具`parallel-clients.spec.ts`覆盖独立profile/管道、后台原生输入只作用于各自页、同站点标签与客户端缩放隔离、缩放使旧截图失效、缩放不改变窗口尺寸，以及窗口位置跨重启恢复。`local-environment.test.mjs`验证本地隔离配置覆盖继承变量。两个项目desktop:check及desktop:build通过；这些夹具结论不代表真实站点筛选配方已校准或JD补采完成。

个人数据库操作、真实岗位样本与历史验收证据保存在本地 `local/private-docs/`。公开仓库的测试使用隔离夹具；实际验证范围以测试输出为准。
